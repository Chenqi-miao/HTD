## 一、模型（Models）

模型定义代码。exp1/exp2 系每个实验目录自带一份**自包含**模型（`<exp>/model/`，含 net/DSF/loss 副本），可独立训练；实验间共享、复用的模块在 `common/` 与 `simple_temporal.py`。

### 1.1 实验自包含模型（每目录一套）

| 文件 | 说明 |
|---|---|
| `exp1_perjoint/model/net.py` | exp1：DSTFormer（2 层时序 Transformer + per-joint Linear 头），位置去噪基线（MPJPE 9.37） |
| `exp2_s15_att/model/net.py` | exp2 s15：joint_embed → JointAttn_pre → TemporalTransformer(8 层 RoPE) → JointAttn_post → Pos/Vel/Acc 三头 |
| `exp2_s30_att/model/net.py` | ⭐ exp2 s31：同 s15、seq_len=31。**LRU+Transformer 混合版 12.18（唯一全量赢家）** 在此目录的 train.py 中 |
| `exp2_s8_att/model/net.py` | exp2 s8：seq_len=8 |
| `exp2_spatialmix/model/` | exp2 变体：8 层时序 Transformer + SpatialMix 空间混合 |
| `exp3_reshape/model/` | exp3：同 pva_paper（PVANetm）结构 |
| `exp5_rope/model/` | exp5：RoPE 相关实验 |
| `exp6_tformer_dec/model/` | exp6：时序 Transformer Decoder 实验 |
| `exp8_smooth/model/` | exp8：平滑相关实验 |
| `exp9_velacc/model/` | exp9：vel/acc 通道实验 |

### 1.2 共享 / 替换的时序与网络模块

| 文件 | 说明 |
|---|---|
| `simple_temporal.py` | ⭐ exp2 时序块替换件。保留 **LRU / LRUTransformer(LRU+8 层 T) / LRUTransformerAlt(交替堆叠)** 三个；DLinear/金字塔/局部注意力/双注意力/动态窗口/DC 偏移等失败架构已删除 |
| `common/bone_ssm.py` | BoneSSM：骨向量提取 → 手尺寸归一化 → Kalman+RTS 平滑 → 位置重建，输出构造性一致的 pos/vel/acc（PVANet 重新设计，见第 7 节设计文档） |
| `common/bone_transformer.py` | BoneTransformer：骨向量 + RoPE 纯时序 Transformer（审计修正版：去 joint_attn_pre、去 DC 泄露、删独立 vel/acc 头） |
| `common/ssm.py` | 可微 Kalman 前向 + RTS 后向平滑器（纯函数，A/Q/R 由模型持有） |
| `common/temporal_transformer.py` | 纯时序 Transformer Decoder + RoPE（剥离空间分支，对比 DSTFormer） |
| `common/rope.py` | RoPE 旋转位置编码 |
| `_tip_net.py` | TipOnlyNet：只修 5 指尖 {4,8,12,16,20}，逐指尖 RoPE 时序、无空间注意力（结果 18.38，失败） |
| `_exp1idx_net.py` | exp1 DSTFormer 方法只跑食指 5 关节（实验失败） |
| `_cascade_net.py` | CascadeIndexNet v3：食指+腕 5 关节、指尖优先级联 + 显式关节身份嵌入（实验失败） |
| `pvanet/` | PVANetm 组件：`motion_encoder.py`（运动编码器）、`temporal_transformer.py`、`vit_encoder.py`、`PVAOptimizer.py`、`PVANetm.py.bak` |
| `exp7_optim/optim.py` | exp7：test-time 优化方法（PVA 优化，非网络结构） |
| `_test_bone_ssm.py` / `_test_bone_transformer.py` | 上面两个新模型的冒烟测试（前向 + loss） |

### 1.3 基础网络部件（各实验 model/ 内复制的通用层）

| 文件 | 说明 |
|---|---|
| `<exp>/model/DSF.py` | DSTFormer 时空双流 Transformer 原始定义 |
| `<exp>/model/loss.py` | SmoothNetLoss（位置 L1 + 加速度 L1，w_accel 可调） |
| `<exp>/model/drop.py` | DropBlock / DropPath（Ross Wightman 实现） |
| `<exp>/model/rope.py` / `<exp>/model/temporal_transformer.py` | RoPE / 时序 Transformer Decoder 的各实验副本 |

## 三、评估和测试方法（Evaluation & testing）

验证 / 指标分析脚本。多数从 `exp10/src/dataloader.py` 读 lazy 数据。

| 文件 | 说明 |
|---|---|
| `verify_exp2_motion.py` | ⭐ exp2 8/15/31 运动保真判定：对齐日志指标(MPJPE/MPJVE/MPJAE, mask) + 速度/加速度 Pearson 相关 + 幅度比 + 高频能量占比 |
| `analyze_motion_fidelity.py` | ⭐ 运动保真深度分析：关节级 + GT 速度分桶 + 输入消融（--mode），兼容消融 checkpoint |
| `verify_polarization.py` | ⭐ 两级分化/抖动分桶验证：--metric mpjpe/mpjve/mpjae/jerk（复刻 train.py 抖动分桶口径），兼容 LRU/混合/Identity checkpoint |
| `analyze_gt_truth.py` | GT 真实性验证：跨相机一致性 / 尖峰关节分布 / 同指时间对齐 |
| `gt_kinematics.py` | GT 抖动统计：速度/加速度/加加速度幅度、CV、lag-1 自相关、峰度 |
| `verify_bone_length.py` | 骨长不变性验证：输入 vs GT 骨长随时间稳定性（CV 等），输出统计 npz |
| `verify_dyn_window.py` | 动态窗口 σ 是否随速度自适应的验证（结论：σ 塌缩，不成立） |
| `_per_joint_fix.py` | 每关节修复程度分析：输入 vs 模型 MPJPE（前 2000 窗） |
| `eval_pva.py` | PVA-Net 全指标评估：MPJPE/MPJVE/MPJAE + PCE@τ，支持 exp1/2/3 |
| `exp10/src/eval_exp1.py` | 全样本流式评估 exp1（8 项指标，292K 样本不占内存） |
| `exp10/src/diagnose.py` | 训练诊断：各模块梯度范数 + 逐关节误差分解 |
| `exp10/src/diag_smoothing.py` | 诊断 PVA 优化是否过度平滑（init/refine/GT 按速度分桶） |
| `exp10/src/optimize_exp1.py` | 用 exp1 的 vel/acc 头做 test-time 优化评估 |
